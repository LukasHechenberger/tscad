The `tscad` command line, from `@tscad/cli`. A new project created with `bun create @tscad` has it installed; run `tscad <command> --help` for the same information in the terminal.

<Cards>
  <Card title="tscad dev" href="/docs/cli/dev">

  </Card>
  <Card title="tscad export" href="/docs/cli/export">

    e.g. .3mf)
  </Card>
  <Card title="tscad analyze" href="/docs/cli/analyze">

  </Card>
