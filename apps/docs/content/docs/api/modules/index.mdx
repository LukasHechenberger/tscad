tscad is a TypeScript library published via npm. If you want to run it locally, you can use the API directly by installing some modules.

**Modules available:**

<Cards>
  {source.pageTree.children
    .flatMap((item) => {
      // A section's overview: its index page, or its first page where meta.json lists "index".
      const overview =
        item.type === 'folder'
          ? (item.index ?? item.children.find((child) => child.type === 'page'))
          : undefined;
      return overview?.url.startsWith('/docs/api/') ? [{ folder: item, overview }] : [];
    })
    .map(({ folder, overview }) => (
      <Card href={overview.url} key={overview.url} title={folder.name}>
        {overview.description}
      </Card>
    ))}
</Cards>
