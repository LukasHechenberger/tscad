tscad is a CAD modeller for programmers. It is designed to provide a modern developer experience with a focus on TypeScript and JavaScript, allowing users to create parametric CAD models using familiar programming languages and modern tools.

## tscad models

A model usually consists of a single TypeScript or JavaScript module, whose default export is the model:

{/* <div className="sticky top-16"> */}

```ts title="A simple tscad model" twoslash
import { cube } from '@tscad/modeling';

export default cube(10);
```

{/* </div> */}

### Building the geometry

Models are built from the primitives and operations in `@tscad/modeling`. Their names follow OpenSCAD, but vectors and options are objects, so every number says what it is.

```ts title="A simple tscad model" twoslash
import { cube, cylinder, difference } from '@tscad/modeling';

/** A cube with a hole through it */
export default difference(
  cube(10, { center: true }),
  cylinder({ h: 12, r: 3, center: true }), // [!code highlight]
);
```

### Define model parameters

You can define parameters for your model using the `defineModel` function, with a schema library such as zod. This allows you to create parametric models that can be easily adjusted: the preview shows a form for them, and the CLI takes them as options.

```ts title="A parametric tscad model" twoslash
import { cube, defineModel } from '@tscad/modeling';
import { z } from 'zod';

// ---cut---
export default defineModel({
  parameters: z.object({ // [!code highlight:3]
    width: z.number().min(1).max(100).default(10),
  }),
// @noErrors
  body: ...
});
```

### Use model parameters

As soon as parameters are defined, the model's `body` receives their values, validated and typed:

```ts title="A parametric tscad model" twoslash
import { cube, defineModel } from '@tscad/modeling';
import { z } from 'zod';

// ---cut---
export default defineModel({
  parameters: z.object({
    width: z.number().min(1).max(100).default(10),
  }),
  body: ({ width }) => cube(width), // [!code highlight]
});
```
